# Renfred Lee — Game Dev Portfolio

Static site for GitHub Pages. No build step.

- `projects.js` — all project cards (edit this to add / change projects)
- `assets/videos/` — project videos (MP4, keep each under ~50 MB)
- `assets/downloads/` — small downloadable builds. Larger builds belong on GitHub Releases.

When you change `styles.css`, `script.js` or `projects.js`, bump the `?v=` number on their links in `index.html` so returning visitors don't get a stale cached copy.
